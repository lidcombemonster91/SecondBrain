## 보류 이유 (2026-11-27)
주로 하려던 일은 릴스의 영상 속 내용을 남기는 것인데, 서버 없는 이 앱으로는 할 수 없다.
릴스 정리는 Meta Muse(Instagram 저장됨 + 커넥터)로 한다. 배포된 앱은 메모용으로 그대로 둔다.
다시 시작하면 아래 iPhone 시험부터 한다. 시험 방법은 임시 HTTPS 터널(cloudflared)로 정했다.
주소(출처)가 실제 앱과 달라서 앱 코드를 바꿀 필요가 없다.

## 다시 시작할 때 할 일: PR #13의 iPhone 시험 (배포 없이)

확인 항목: PDF 선택·미리보기·원본 열기, 본문 검색, 요약 요청문 복사, 삭제, 저장소 보존 상태, 오프라인,
**20MB에 가까운 PDF 5개(약 100MB)를 내보내고 빈 앱에서 가져오기**.
앱이 멈추거나 실패하면 배포하기 전에 알리고, 백업 형식·방식을 바꾸기 전에 승인을 받습니다.
기존 데이터는 유지해야 합니다.

시험 방법은 아직 정하지 않았습니다. 후보:
- 시험 전용 공개 저장소의 GitHub Pages. 실제 앱과 웹 출처가 같으므로, 복사본의 DB 이름,
  `lastBackupAt` 키, 캐시 이름을 바꾸고 `sw.js`가 시험용 캐시만 지우게 해야 합니다.
  실제 앱의 `sw.js`는 다른 캐시를 지우므로, 시험 중에는 실제 앱을 열지 않습니다. (승인 전)
- 가짜 시험 PDF는 `tests/pdf-fixtures.cjs`의 `textPdf`, `koreanPdf`, `sizedPdf`로 만듭니다.

## 4단계 전에 할 일
- `tests/memo.test.cjs`의 한국어 시험에 `ko-KR` locale 지정 (직접 브라우저 context를 만드는 시험 포함)
- 새 화면 문구(PDF 포함)를 번역 사전으로 옮기고, 단축어 안내를 설정 화면으로 이동

## 작업 규칙
- 단계마다 PR 하나. merge(= 배포)는 매번 승인. 이전 PR이 merge된 뒤 다음 단계를 시작합니다.
- force push와 기존 branch 삭제는 하지 않습니다.
- 기존 시험의 확인 항목을 지우거나 약하게 만들지 않습니다.
